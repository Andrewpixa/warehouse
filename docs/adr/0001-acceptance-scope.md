# ADR-0001 本期验收口径冻结

- 状态：已采纳（2026-09-14）
- 决策方：项目组书面冻结，提交甲方确认

## 背景

仓库里同时存在「通用门店进销存」与「药企流通链路」。介绍页、项目情况说明此前只写了「怎么看」，未书面规定验收以哪条为准；移动端仍在开发。若不冻结，演示环境会被误当成生产交付。

## 决策

1. **本期验收主链路 = 药企药品流通**：品种档案 → 采购入库（批号/效期）→ 批号库存 → 追溯码（系统内采集/查询/本地包装解析）→ 销售出库 → 医院收货 → 日清 / 月结。
2. **通用门店进销存不列入本期验收**：进货 POS、销售 POS、散客零售、会员、提成、序列号门店流等，仅作对照演示。
3. **移动端 / 桌面端不列入本期验收**：uni-app X、Flutter、Electron 均为开发中。
4. **公网 `http://IP` + `admin/123456` 不能作为生产交付**。生产形态必须是独立备案域名 + HTTPS，且按采购/仓管/销售/财务配置人员并废止长期超管弱口令。
5. **码上放心、GSP 岗位按贵司落地**：现为待确认，不是已交付。

## 后果

- 验收证据只对第 1 条主链路出具实测记录。
- 未列入本期的能力，即使页面能打开，也不构成验收通过。
- 生产开通依赖甲方提供备案域名与岗位人员名单；在此之前环境定性为「公网演示」。

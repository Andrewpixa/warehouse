# AI 使用声明

原则：用过就写明用在哪一段，以及用什么核对过。核对不了的不留在主链路里。

| 用途 | 用在哪 | 如何验证 |
|---|---|---|
| 生成 CRUD 和页面初稿 | 档案、单据列表等常规增删改 | 打开对应菜单，保存一条再查出来 |
| SQL 与并发建议 | `BatchStockMapper.decreaseIfEnough` | 出库数量大于批号库存时，确认失败，库存数量不变 |
| 文档和分享稿 | `docs/course/` 讲稿、选型说明 | 和 `/design` 的用例编号、线上地址对照 |
| 报错定位 | 构建或接口报错时的日志阅读 | 按修改后再跑一次原来的操作 |

分享时如果被问到某一段是不是 AI 写的：先说是哪一段，再说上表里的验证动作。没有验证过的，直接说没有验证。

| 角色 | 主操作 | 不要用这个号演示 |

| 超级管理员 | 全菜单应急 | 日常开单（生产禁用） |

## 5. 对外必须说清的三句话

1. **这是演示库。** 品种、医院、批号、追溯码都是样例。  
2. **公网 HTTP + 弱口令不是生产交付。** 生产要独立域名、HTTPS、实名岗位账号（见 01、06）。  
3. **「解析包装 / 追溯查询」是系统内数据，不是码上放心监管接口**（见 04）。

操作步骤细节见 [07 操作手册](./07-操作手册.md)；账号生产切换见 [06 账号权限初始化](./06-账号权限初始化.md)。

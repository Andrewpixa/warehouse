# 07 操作手册（药企主链路）

适用：Web 后台。移动端不在本期。生产应以 `https://<备案域名>` 打开；下文路径相同。

演示环境仍为 `http://123.57.134.57`，仅供对照，**不是**交付形态。

## 登录

1. 打开登录页。  
2. 输入岗位账号（生产禁用 `admin/123456`）。  
3. 输入验证码（点击图片刷新）。  
4. 进入工作台。会话过期会回到介绍页。

## 采购入库

1. 菜单 **采购入库 → 采购入库单**。  
2. 新建草稿：供应商、仓库、业务日期。  
3. 明细必填：品种、**批号**、生产日期、**有效期至**、收货/合格/入库数量、质量状态。  
4. 整单验收结论为 **合格**，且明细无待验/不合格，才能点确认。  
5. 确认后批号库存增加，草稿不可再改。

## 批号库存

1. 若侧栏无入口：顶栏预警「去批号库存查看」，或打开 `/business/batch-stock`（生产补菜单后从 **仓储质量** 进入）。  
2. 可按品种、批号、仓库、质量、近效期 90 天 / 已过期筛选。  
3. 粒度：药品 × 仓库 × 批号 × 质量状态。

## 销售出库

1. **销售出库 → 销售出库单**，草稿选客户、仓库。  
2. 明细必填批号、数量、单价。  
3. 确认发货时扣减对应批号库存；不足则提示「库存不足：药品…批号…现有…需要…」，单据保持草稿。  
4. 确认后进入 **待收货**（红冲单不加待收货）。

## 追溯码

1. **销售出库 → 追溯码查询**。  
2. 输入 20 位发票号查询：出库头、明细 SPDID、已采码。  
3. 「采集追溯码」写入最小包装码；重复码会提示「追溯码已存在」。  
4. 「解析包装」仅展开本库预置包装树，**不是**码上放心。

## 医院收货

1. **销售出库 → 医院收货确认**。  
2. 待收货单据可签收或拒收；实收不能大于发货。  
3. 已签收/非待收货再提交会失败。不要对同一单连点两次。

## 日清 / 月结

- **仓储质量 → 日清检查**：按日核对出入库与缺码等项。  
- **仓储质量 → 月结对账**：按月确认；确认后按系统提示不可随意重做。

## 异常怎么记

发给实施人员时请带：**菜单名 + 单号/发票号/批号/追溯码 + 时间 + 截图**。不要在工单里写生产口令。

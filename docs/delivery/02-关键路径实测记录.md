## 4. 追溯码

页面 `/business/trace?invoiceNo=20260907000100000001` 实测：

- 出库单 `CK20260907001`，客户「南方医科大学南方医院」，仓库广深惠，状态已确认
- 明细：阿莫西林胶囊 / 批号 **AMX20260801** / 数量 40 / SPDID **SPD202609071101** / 已采码 2
- 码值：
  - `01069212345678931728073110AMX20260801`
  - `01069212345678931728073110AMX20260802`
  - 包装层级：最小包装；业务：出库；状态：正常

重复采集同一码：

```
POST /warehouse/trace/addCodes
{ spdid: SPD202609071101, codes: [01069212345678931728073110AMX20260801] }
→ code=-1  追溯码已存在：01069212345678931728073110AMX20260801
```

本地包装解析（**不是**码上放心接口）：

```
GET /warehouse/trace/previewParse?code=81000000000000000001
→ 9 行：1 大包装 + 2 中包装 + 6 最小包装
```

**结论：** 发票号 → 批号 → SPDID → 追溯码可核对；系统内防重复采码通过。监管平台未对接（见 04）。

## 5. 防超卖（出库扣批号库存）

现存量：阿莫西林 `AMX20260801` = **160**。

1. 保存草稿出库 `CK202609143084`（id=9），数量 **9999**，备注「验收防超卖用例」。
2. 确认出库：

```
库存不足：药品「阿莫西林胶囊」批号 AMX20260801 现有 160.000，需要 9999.000
```

3. 删除该草稿成功。复查明细库存仍为 **160**。

**结论：** 按批号原子扣减生效，超卖被拒绝，库存未脏写。

## 生产窗口（须在 HTTPS 开通同一天完成）

1. 甲方提供真实姓名、部门、岗位（采购 / 仓管 / 销售 / 财务；超管 1～2 名实名）。  
2. 在「人员信息」为每人建号，登录名不用 `admin`。  
3. 用系统「重置密码」或改密接口设置密码柜中的强口令（≥12 位，柜内各不相同）。  
4. 「角色管理」勾选对应角色；不要把超管角色批给业务岗。  
5. 用各岗位账号登录，确认菜单与 00 主链路匹配（采购能入库、仓管能库存/追溯、销售能出库/收货、财务看统计只读）。  
6. 将 `admin` 的 `available` 置 0，或改密后仅放应急柜、禁止日常使用。  
7. 演示库若升为生产：删除或停用样例医院/批号/追溯码，或切换空库再导入。

停用超管（在确认已有实名超管可登录之后）：

```sql
UPDATE sys_user SET available = 0, remark = '生产已停用弱口令超管' WHERE loginname = 'admin';
```

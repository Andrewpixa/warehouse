# 00 范围冻结与验收口径

**效力：** 本期书面冻结。与 ADR-0001 一致。甲方若需改口径，须另发书面确认后再改验收范围。

## 1. 验收以哪条为准

| 口径 | 是否本期验收 | 说明 |
|------|----------------|------|
| **药企药品流通主链路** | **是** | 唯一验收基准 |
| 通用门店进销存（POS / 零售 / 会员 / 提成等） | **否** | 代码仍保留，仅对照演示 |
| 移动端（uni-app X / Flutter） | **否** | 开发中 |
| 桌面端（Electron） | **否** | 开发中 |

主链路（必须能走通并留痕）：

1. 品种 / 供应商 / 客户档案  
2. 采购入库单：批号、效期、验收合格后确认入库  
3. 批号库存：药品 × 仓库 × 批号 × 质量状态  
4. 追溯码：按发票号 / SPDID 查询；系统内采集；本地包装树解析  
5. 销售出库：按批号扣库存；库存不足拒绝  
6. 医院收货：待收货 → 签收；重复提交拒绝  
7. 日清检查、月结对账  

## 2. 什么不算本期交付

- 公网长期 `http://IP` + `admin/123456`
- 对接「码上放心」等监管平台（见 04）
- 按贵司编制落地的 GSP 岗位与权限（见 04、06）
- 正式主数据替换演示数据
- 手机端外勤扫码、桌面仓作业

## 3. 环境分层

| 环境 | 用途 | 可否作为交付 |
|------|------|----------------|
| 公网演示（当前） | 远程看介绍页、走主链路样例 | **否** |
| 生产（待开通） | 独立域名 + HTTPS + 岗位账号 + 正式数据 | **是**（开通条件全部满足后） |

演示库里的品种、批号、医院客户、追溯码均为样例，**不等于**贵司正式数据。
